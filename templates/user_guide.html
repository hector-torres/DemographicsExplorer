00 Interface Overview

The Demographic Dashboard integrates Texas Census demographic data, 2020–2024 election results, LODES workforce data, and political district boundaries into a single analytical environment for strategic communications work.

01 Geography

Census Layer

Toggle between PUMA (217 regional geographies, 100,000+ people each) and Tract (~6,900 neighborhood-level geographies). Default is Tract. LODES workforce data is only available at the Tract level.

Scope to District / County

Select an overlay type to scope the entire dashboard to a specific geography. All census features, election VTDs, and percentile calculations narrow to the selected area.

02 Demographic Analysis

Select any field from the Display Variable search to color-code the map. The Stats panel (bottom-right) updates with field statistics and a color scale legend.

Pinned Favorites (★)

Every field in every view shows a ★ button on hover. Click to pin to ★ PINNED. The star turns amber when pinned. Click again to unpin. Useful for building a personal shortlist of fields for a specific client or project.

Middle-range filtering

Set low=25, high=75 on any field to keep only the middle 50% of tracts — ideal for targeting moderate geographies and excluding statistical outliers at both ends.

Audience Filters

Minimum Population — set a minimum resident count to exclude low-population rural tracts that skew percentile analysis. Recommended: 1,500–2,000 for statewide work.

Percentile Filters — filter tracts to BOTTOM X% or TOP X% on any field. All filters combine with AND logic.

Minimum Count Filters — filter by raw count minimums (e.g. Hispanic population AT LEAST 500). Essential for ensuring "high share" filters represent real audience volume.

Best Practice

Combine share filters (percentile) with count filters to define a well-scoped audience: Hispanic TOP 30% AND Hispanic AT LEAST 300 people = high-concentration tracts with meaningful population.

Audience Reach Panel

Click REACH ↗ in the Layer Stats panel to open the Audience Reach panel. It calculates total audience size across all filtered tracts: population, registered voters, 2024 turnout, Hispanic count, college-educated count, Spanish-speaking households, WFH count, and housing tenure.

  • 1Set geographic scope (county or district overlay)
  • 2Apply demographic filters until you have a targeted profile
  • 3Open Reach panel to see total addressable audience size
  • 4Adjust filters if universe is too broad or too narrow
  • 5Export the filtered data for use in targeting platforms

Swing Field Interpretation

Positive swing value = R gained ground. Negative value = D gained ground. The election layer respects all active geographic and demographic filters.

Swing fieldWhat it reveals

04 Feature Profile

Click any census tract, PUMA, political district boundary, or VTD on the map to open a full profile in the sidebar. The profile shows all 30 marketing fields with percentage-of-total annotations where applicable, expandable to all 150+ raw fields.

— Strategic Workflows

Finding Persuadable Audiences

  • 1Set Census Layer to Tract
  • 2Enable SHOW VTD LAYER → select R−D Margin (Pres 2024)
  • 3Select Median Household Income as Display Variable
  • 4Look for middle-income tracts (mid-color) overlapping light-colored VTDs (low margin)
  • 5Open Reach panel to size the universe

Latino Audience Strategy

Mobilization targets: Enable VTD layer → select SS Turnout Change 2020→2024. Blue VTDs = declining Latino turnout. Cross-reference with Hispanic % display variable. Dark census + blue VTD = high-priority mobilization geography.

Persuasion targets: Add percentile filter hispanic → TOP 30%. Look for VTDs with margins under 20 points.

District-Level Strategy

  • 1Enable US CONGRESS overlay → search for target district
  • 2Map zooms; census and VTD layers filter to the district
  • 3Click district boundary → full population-weighted profile in Section 04
  • 4Click ▶ COLOR BY DISPLAY VARIABLE to compare all 38 districts at once

Swing Analysis Workflow

  • 1Set county or district scope
  • 2Enable VTD layer → select Pres Swing R 2020→2024
  • 3Red = R momentum, Blue = D momentum
  • 4Switch to Gov→Pres Swing 2022→2024 — where did Trump underperform Abbott? These precincts contain ticket-splitters.
  • 5Cross-reference with census demographics to identify who is driving the swing

— Startup Loading Screen

On first launch and after every server restart, a full-screen card displays while all data loads into memory. This takes 2–4 minutes and happens once per server session.

ElementDescription
Progress barSmooth fill from 0–100% as each step completes
PercentageExact completion (e.g. 63%)
Step list17 steps with live status: · pending, ▶ running (pulsing blue), ✓ done, ✗ error
Step notesCompletion details per step, e.g. "6,892/6,900 matched, 5 indices"
